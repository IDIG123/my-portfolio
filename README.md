# my-portfolio

My personal portfolio website built for Phantom (my first hackathon), made with HTML and Tailwind CSS.

Live Demo: https://idig123.github.io/my-portfolio/

# What's on the Site
- Intro: A quick introduction about me, being 15, using Linux, and getting into coding.
- Linux Setup: A showcase of my current Arch Linux desktop setup with a screenshot.
- Featured Projects: A 3-column showcase of other projects I've built over the past few years:
  - Auto Fisher: A Minecraft auto-fisher using virtual inputs, drop tracking, notifications, and customizable settings.
  - Playground Mods: A mod manager and downloader for *People Playground* that pulls mod files from third-party sites and organizes installed mods.
  - OpenG Act: A mouse control center built for Arch Linux to manage profiles, DPI, lighting, and battery on my G502.
# Built With
- HTML5
- Tailwind CSS (CDN)
- Google Fonts (`Rubik`)
- Hosted on GitHub Pages
